How it works

01

Data Preprocessing

Clean and normalize the questions — lowercasing, removing punctuation and extra whitespace.

02

Feature Extraction

Convert text into numerical features using TF-IDF, then compute cosine similarity, word overlap and length difference.

03

Prediction

A Logistic Regression model, trained on these features, predicts whether the questions are duplicates.

About this project

Problem statement. Platforms like Quora receive many questions that ask the same thing in different words. Automatically detecting duplicate questions helps route users to existing answers instead of creating redundant threads.

Dataset. The model is trained on the Quora Question Pairs dataset, which contains pairs of questions along with a label indicating whether they are duplicates.

TF-IDF. Term Frequency–Inverse Document Frequency turns each question into a vector that reflects how important each word is, relative to the whole dataset.

Logistic Regression. A simple, interpretable classifier trained on similarity-based features (cosine similarity, word overlap, length difference) to output a duplicate / not-duplicate decision.

Evaluation metrics. Accuracy, Precision, Recall, F1 Score and a Confusion Matrix are used to measure how well the model performs on unseen test data.
